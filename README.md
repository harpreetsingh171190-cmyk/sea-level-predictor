# Sea Level Predictor

This project is part of the **Data Analysis with Python** certification from freeCodeCamp. It uses Python, Pandas, Matplotlib, and SciPy to analyze a dataset of global average sea level change since 1880 and predict changes through the year 2050.

## Features & Tasks
- **Scatter Plot:** Visualizes the relationship between years and CSIRO Adjusted Sea Level[span_1](start_span)[span_1](end_span).
- **Line of Best Fit (1880-2014):** Calculates and plots the first line of best fit across the entire dataset extending to 2050[span_2](start_span)[span_2](end_span).
- **Line of Best Fit (2000-2014):** Calculates and plots a second line of best fit based on recent data from the year 2000 onwards to project future rise rates[span_3](start_span)[span_3](end_span).
- **Custom Labels:** Properly labels x-axis as `Year`, y-axis as `Sea Level (inches)`, and sets the title to `Rise in Sea Level`[span_4](start_span)[span_4](end_span).
